## PROMPT 4 — Create Character Image Prompts for Every Character
Based on the complete Nepali animated story above, identify every character used in the story and create a detailed image-generation prompt for each character.
The character designs must be suitable for a 2D cartoon animated Nepali village story.
### Important Requirements:
Every character must have a unique and memorable visual identity.
Character faces must remain consistent throughout the entire story.
The same character must look identical in every scene.
Create a strong character reference sheet for animation consistency.
All characters must look naturally connected to the Nepali setting.
Use authentic Nepali clothing, hairstyles and physical characteristics suitable for the character’s age, occupation and village background.
Do not use random foreign fashion or unrelated cultural designs.
